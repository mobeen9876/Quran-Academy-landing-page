How it works

Three steps, repeated every day your madrasa is open.

1

Assign a plan

Pick a memorization plan and a start date. The system builds the full schedule, skipping holidays automatically.

2

Record the day's result

After each session, the teacher marks what was recited, what was revised, and how it went.

3

Parent gets notified

A WhatsApp message goes out immediately — no dashboard login required on the parent's side.

Questions, answered

Do we need technical staff to set this up?

No. Any teacher can learn the day-to-day use in about five minutes. We handle the initial setup with you, including importing your existing student list.

How long does setup take?

Most madaris are fully set up within a day — students added, plans assigned, and the first WhatsApp update sent.

Do parents need to verify their WhatsApp number?

Yes, a one-time verification confirms the right number is on file, so updates never go to the wrong parent.

Is Nizam-e-Qurani available in Arabic?

Yes — the full system, including WhatsApp messages, works in both Arabic and English.

What happens to schedules on a holiday?

Add the holiday once in the admin dashboard, and every student's schedule shifts around it automatically — no manual rework.
